# IP Camera Network Installation & NVR Setup

## Project Overview

This project involved the installation of an IP-based CCTV surveillance network using IP cameras, a Gigabit PoE switch, an NVR (Network Video Recorder), structured Ethernet cabling, and a network rack.

The project provided practical experience in network cabling, PoE connectivity, network equipment installation, and IP camera/NVR connectivity.

## Objectives

- Install and organize network equipment
- Install and route Ethernet cables for IP cameras
- Connect IP cameras through a PoE switch
- Connect the PoE switch to the NVR
- Install network equipment inside a rack
- Verify network connectivity
- Set up camera monitoring through the NVR

## Equipment Used

- IP Cameras
- NVR (Network Video Recorder)
- Gigabit PoE Switch
- Network Rack
- Ethernet/UTP Cables
- RJ45 Connectors
- Monitor

## Installation Process

### 1. Equipment Preparation

The network equipment was inspected and prepared before installation, including the PoE switch and NVR.

### 2. Ethernet Cable Installation

Ethernet cables were routed from the camera locations toward the network rack.

### 3. Network Rack Installation

A wall-mounted network rack was installed to organize the network equipment and cabling.

### 4. PoE Switch Installation

The Gigabit PoE switch was installed and connected to the Ethernet cables coming from the IP cameras.

PoE allows compatible IP cameras to receive power and network connectivity through Ethernet cabling.

### 5. NVR Installation

The NVR was connected to the network infrastructure for receiving, recording and managing IP camera streams.

### 6. Connectivity Testing

Camera connections and network connectivity were checked to verify communication between the IP cameras, PoE switch and NVR.

### 7. Monitoring Setup

The NVR was connected to a monitor to verify camera availability and monitoring functionality.
